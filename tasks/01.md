Hoje, todas as minhas chamadas de API que são cacheadas não possuem um TTL de expiração. O que faz com que o cache nunca seja invalidado após um período de tempo. Quero adicionar um TTL que faça sentido para cada cache e sua respectiva funcionalidade.

## Regras de negócio

- Adicione um TTL em segundos para cada cache.
- Seja justo com o TTL baseado em cada cache.
- Não altere a lógica de invalidar o cache manualmente.
- Não remova o cache de nenhum lugar.
- Não altere a lógica de cache.
- Se necessário, adicione cache em algum lugar que faça sentido.
